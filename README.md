# VarHeroes - Magneto Heropack

🦾 **Magneto heropack для FiskHeroes мода**

## 📋 Содержимое

### Герои
- **Magneto** (Уровень 8)
  - Телекинез с управлением колёсиком мыши
  - Магнитная левитация
  - Магнитный импульс
  - Электромагнитный щит

## 🎮 Управление

| Кнопка | Способность | Описание |
|--------|------------|----------|
| **1** | Телекинез | 🧠 Колёсико мыши для притягивания/отталкивания |
| **2** | Левитация | 📈 Полёт при нажатии SHIFT |
| **3** | Магнитный импульс | 💥 Взрывная волна магнитной энергии |
| **4** | Щит | 🛡️ Электромагнитная защита |

## 📁 Структура

```
varheroes/
├── data/
│   ├── heroes/magneto.js          # Основной файл героя
│   ├── powers/                    # Файлы способностей
│   │   ├── magnetic_powers.json
│   │   └── electromagnetic_field.json
│   ├── fabricator/heroes.json     # Регистрация героев
│   └── tags/heroes.json           # Теги
├── assets/
│   └── minecraft/sounds.json      # Звуки
└── pack.mcmeta                    # Метаданные
```

## 🎨 Текстуры (в разработке)

Текстуры брони находятся в папке `assets/varheroes/textures/armor/`:
- `magneto_layer_1.png` - основной слой
- `magneto_layer_2.png` - дополнительный слой

## 📥 Установка

1. Скачайте этот heropack
2. Поместите папку в директорию модов FiskHeroes
3. Перезагрузитесь в игре
4. Выберите Magneto в меню героев

## 🔧 Требования

- FiskHeroes мод (версия 1.20.1+)
- Minecraft 1.20.1+
